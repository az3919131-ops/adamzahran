# اللوحة المهنية — م. أحمد زهران

موقع شخصي تفاعلي + لوحة إدارة لتحديث السيرة الذاتية والخبرات والمهارات والمنصات والقنوات دون تعديل الكود.

## التشغيل
- **الصفحة العامة (معرض المنصات):** `/`
- **صفحة السيرة الذاتية:** `/#/cv`
- **لوحة الإدارة:** `/#/admin` (تتطلب رمز الإدارة)
- **المعاينة قبل النشر:** `/#/preview`

## البنية
| المسار | الوصف |
|---|---|
| `public/` | الواجهة (HTML/CSS/JS بدون خطوة بناء) |
| `public/assets/seed.js` | البيانات الأولية |
| `public/assets/content-v9.js` | محتوى المعرض: الرسالة الرئيسية، أوصاف المنصات، الخدمات |
| `public/assets/home.js` + `site.css` | الصفحة الرئيسية: المشهد ثلاثي الأبعاد (CSS + SVG بدون WebGL)، صفوف المنصات، نافذة «شاهد كيف تعمل» والعرض التوضيحي |
| `public/assets/shots/` | لقطات حقيقية من واجهات المنصات |
| `public/assets/content-v10.js` + `cv.js` + `cv.css` + `scene3d.js` | صفحة السيرة الذاتية (`/#/cv`): الخبرات، دراسات الحالة، قاعدة الشهادات، المشهد ثلاثي الأبعاد (Three.js) |
| `public/assets/certs/` | صور الشهادات **بعد تغطية الأرقام الشخصية داخل ملف الصورة نفسه** (لا تُنشر ملفات PDF الأصلية) |
| `netlify/functions/api.mjs` | واجهة برمجية: المحتوى، الإعدادات الخاصة، نموذج التواصل، الرد التلقائي، الملفات |
| `tests/` | اختبارات شاملة (Playwright) مع خادم محلي |

## الحماية والتخزين
- التخزين: **Netlify Blobs** (المحتوى، النسخ السابقة، الإعدادات الخاصة، سجل الرسائل، الملفات).
- المصادقة: متغير البيئة `ADMIN_TOKEN` في إعدادات Netlify (12 حرفًا على الأقل). يُتحقق منه على الخادم في كل عملية كتابة.
- رابط Webhook يُحفظ في الخادم فقط ولا يُرسل للزوار.
- عند فتح الملفات دون خادم (محليًا) يعمل التطبيق في **وضع الحفظ المحلي** (LocalStorage) مع تنبيه واضح.

## الرد التلقائي (Webhook)
عند إرسال نموذج التواصل يرسل الخادم JSON إلى الرابط المحفوظ:
```json
{ "type": "contact_message", "test": false, "name": "...", "contact": "...", "subject": "...",
  "message": "...", "lang": "ar", "submittedAt": "ISO-8601", "source": "https://..." }
```
لا تظهر رسالة «تم الاستلام» للعميل إلا إذا رد الرابط بحالة 2xx.

## الشهادات والخصوصية
- معاينات الشهادات صور JPEG رُسم فوق أرقام الهوية والإقامة وتواريخ الميلاد فيها (التغطية داخل البكسلات وليست CSS)، ولا توجد ملفات PDF في الموقع.
- قبل إضافة معاينة جديدة من لوحة الإدارة: غطِّ أي رقم هوية أو إقامة أو تاريخ ميلاد في الصورة قبل رفعها.
- نموذج التواصل يُسلَّم عبر Webhook (إن ضُبط)، وإلا عبر **Netlify Forms** (النماذج تظهر في لوحة Netlify ← Forms). لا تظهر رسالة نجاح إلا إذا قبلت إحدى الخدمتين الطلب.
- واجهة `GET /api/certificates?tab=&q=` تعيد الشهادات المنشورة بصيغة JSON.
