# اللوحة المهنية — م. أحمد زهران

موقع شخصي تفاعلي + لوحة إدارة لتحديث السيرة الذاتية والخبرات والمهارات والمنصات والقنوات دون تعديل الكود.

## التشغيل
- **الصفحة العامة:** `/`
- **لوحة الإدارة:** `/#/admin` (تتطلب رمز الإدارة)
- **المعاينة قبل النشر:** `/#/preview`

## البنية
| المسار | الوصف |
|---|---|
| `public/` | الواجهة (HTML/CSS/JS بدون خطوة بناء) |
| `public/assets/seed.js` | البيانات الأولية (من البرومت فقط) |
| `netlify/functions/api.mjs` | واجهة برمجية: المحتوى، الإعدادات الخاصة، نموذج التواصل، الرد التلقائي، الملفات |
| `tests/` | اختبارات شاملة (Playwright) مع خادم محلي |

## الحماية والتخزين
- التخزين: **Netlify Blobs** (المحتوى، النسخ السابقة، الإعدادات الخاصة، سجل الرسائل، الملفات).
- المصادقة: متغير البيئة `ADMIN_TOKEN` في إعدادات Netlify (12 حرفًا على الأقل). يُتحقق منه على الخادم في كل عملية كتابة.
- رابط Webhook يُحفظ في الخادم فقط ولا يُرسل للزوار.
- عند فتح الملفات دون خادم (محليًا) يعمل التطبيق في **وضع الحفظ المحلي** (LocalStorage) مع تنبيه واضح.

## الرد التلقائي (Webhook)
عند إرسال نموذج التواصل يرسل الخادم JSON إلى الرابط المحفوظ:
```json
{ "type": "contact_message", "test": false, "name": "...", "contact": "...", "subject": "...",
  "message": "...", "lang": "ar", "submittedAt": "ISO-8601", "source": "https://..." }
```
لا تظهر رسالة «تم الاستلام» للعميل إلا إذا رد الرابط بحالة 2xx.
